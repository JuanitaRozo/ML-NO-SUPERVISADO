# Machine Learning No Supervisado

## Descripción
Se implementaron técnicas de **Clustering** y **Reducción de Dimensionalidad** para analizar y visualizar patrones en diferentes conjuntos de datos.

## Técnicas implementadas

- **K-means:** agrupación de datos mediante centroides.
- **Clustering Jerárquico:** agrupación mediante relaciones jerárquicas y dendrogramas.
- **PCA:** reducción de dimensionalidad mediante componentes principales.
- **SVD:** factorización matricial y reducción de dimensionalidad.
